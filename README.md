# MultiThreading Learning Lab

A comprehensive Java laboratory for mastering **MultiThreading and Concurrency**. This repository contains modular examples and practical demonstrations of core threading concepts, synchronization mechanisms, and deadlock resolution.

---

## 🚀 Learning Roadmap

This project is organized into sequential modules to facilitate a step-by-step understanding of the Java Concurrency API:

| Module | Topic | Key Concepts |
| :--- | :--- | :--- |
| **01** | [ThreadLifeCycle](./ThreadLifeCycle) | New, Runnable, Blocked, Waiting, Timed Waiting, Terminated. |
| **02** | [Thread-VS-Runnable](./Thread-VS-Runnable) | Class inheritance vs Interface implementation. |
| **03** | [Synchronized-Keyword](./Synchronized-Keyword) | Mutual exclusion and preventing race conditions. |
| **04** | [ReentrantLock](./ReentrantLock) | Explicit locks and **Lock Fairness** policies. |
| **05** | [ReadAndWriteLock](./ReadAndWriteLock) | Optimizing performance for read-heavy scenarios. |
| **06** | [deadLock](./deadLock) | Identifying and resolving circular dependencies. |
| **07** | [thread-Communication](./thread-Communication) | Inter-thread signaling with `wait()`, `notify()`, and `notifyAll()`. |

---
